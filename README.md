# Kanban Board

Полнофункциональная система управления задачами (клон Trello), разработанная с нуля.

## Стек технологий

**Backend:**
- NestJS (фреймворк)
- PostgreSQL (реляционная база данных)
- Prisma ORM (работа с базой данных и миграции)
- JWT (авторизация и защита маршрутов)
- Swagger (документация API)
- Docker (контейнеризация БД)

**Frontend:**
- Vanilla JavaScript (без фреймворков, чистый JS)
- HTML5 Drag & Drop API (перетаскивание карточек)
- CSS3 (верстка)

## Функционал

- Регистрация и авторизация пользователей (JWT).
- Создание, удаление и просмотр досок.
- Участники досок (добавление пользователей по email).
- Создание колонок (To Do, In Progress, Done создаются автоматически).
- Создание карточек с описанием и дедлайном.
- Drag & Drop — перемещение карточек между колонками.
- Комментарии к карточкам.
- Полноценная документация API (Swagger).
